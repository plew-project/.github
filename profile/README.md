# PLeW

Interactive multi-dimensional data visualizer. Load CSV or JSON, map columns to grid axes, color, shape, and panels, then explore records in a scatter-grid.

## Repositories

| Repo | What it is |
|------|------------|
| [**PLeW**](https://github.com/plew-project/PLeW) | Main editor and example gallery |
| [**PLeW-NLG**](https://github.com/plew-project/PLeW-NLG) | Research fork (NLG / paper experiments) |
| [**PLeW-Map, "Maplew"**](https://github.com/plew-project/maplew) | Research fork (continuous data / world englishes) |
| [**home**](https://github.com/plew-project/home) | Landing page with links to live demos |
